# BigBroActivator WA

BigBroActivator WA by BigBroActivator WA.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/bigbro-activator-wa/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **BigBroActivator WA** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/bigbro-activator-wa/releases/latest) and reinstall.
